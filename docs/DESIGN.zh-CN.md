# Web Tools 设计指南

为高频链接、动画和图片任务构建紧凑工作区。正式界面遵循已评审的 F 设计：蓝色主操作、浅蓝次要操作、清晰的语义反馈、窄任务控件和可见画布。原型文件仅供参考，不作为正式运行时依赖。

公开目录和工具切换器只展示 URL 与二维码、帧动画、Lottie 预览和点九图。CSS 扫光与字体工具箱保留直达路由。`apps/web/src/tools/index.ts` 中的注册表是导航的唯一来源。不要增加数据位置或上传行为的宣传文案。

## 导航与密度

- `SiteHeader` 统一管理共享顶栏、左侧返回首页、公开工具切换器、主题控件和仓库链接。工具工作区不要重复这些内容，也不增加常驻侧栏导航。
- 顶栏高于普通画布控件、低于模态遮罩。切换器在导航、外部指针操作或 Escape 后关闭；Escape 将焦点还给摘要按钮。
- 使用紧凑间距与控件。不要在工具上方加入大型 Hero。画布工作区将窄任务控件放在主画布旁；手机上堆叠控件或使用标签页，保持核心操作可达。
- 首页目录桌面为紧凑四列，手机为两列。用细边框和间距区分分组，避免装饰阴影、渐变和浮起卡片。

## 语义颜色

所有颜色来自 `apps/web/src/index.scss`。组件中禁止写死颜色，包括 `bg-blue-500` 等 Tailwind 色板类。正式亮暗色板无需开发开关即可生效。

| 用途                       | 令牌                                                               |
| -------------------------- | ------------------------------------------------------------------ |
| 页面与文字                 | `background`, `foreground`                                         |
| 面板与弹层                 | `card`, `card-foreground`, `popover`, `popover-foreground`         |
| 主操作与焦点               | `primary`, `primary-foreground`, `ring`                            |
| 次要操作与选中             | `secondary`, `secondary-foreground`, `accent`, `accent-foreground` |
| 辅助内容                   | `muted`, `muted-foreground`                                        |
| 边框与表单控件             | `border`, `input`                                                  |
| 成功、危险、警告和提示反馈 | `success`, `destructive`, `warning`, `info`                        |
| 装饰图表                   | `chart-1` 至 `chart-5`                                             |

每个反馈色族包含实色、`-foreground`、`-muted` 和 `-muted-foreground` 变体。颜色同时配合文字标签或图标。实色操作使用匹配的前景色；浅色反馈使用匹配的 muted 前景色。成功反馈替换主操作状态时仍须清晰可读。显式建模消息语义，不从翻译后的字符串推断类型。

## 控件与排版

- 复用 `Button`。纯图标操作无可见边框，保留悬停、选中、禁用和键盘焦点反馈。每个图标操作需要无障碍名称。共享主题操作为等大的 30px 方形。
- 悬停和按下只改变颜色，使用短过渡。悬停时不要位移或缩放控件。避免阴影和装饰性动效。
- 标题、数字和代码用 `font-mono`，正文用 `font-sans`。优先紧凑标题和可读辅助文字。测量值使用等宽数字。
- 表单标签清晰并靠近字段。关联值分组；分段选项暴露选中状态。控件、字段和文字在两套主题中都须可用。
- 所有工具内容使用语义令牌。语义反馈和选中状态可以使用各自不同色相；蓝色是主操作色相，并非唯一允许的色相。

## 画布查看与编辑

图片查看复用 `apps/web/src/lib/stage.ts` 及 `StageViewControls` / `useStageViewSettings`。

- 默认视图将可见内容的联合矩形完整适配舞台。通过滚轮、触控板捏合或双指在 1% 至 800% 之间缩放；缩放和平移不改变导出像素或输出参数。
- 缩放手势后短暂显示当前比例。重置视图恢复适配与居中，独立于编辑和输出设置。
- 任何缩放级别都可拖动平移。平移捕获指针前，先保护切线、缩放手柄、按钮及其他编辑交互。画布接管触摸手势时，使用原生非 passive 滚轮处理与 `touch-none`。
- 外层布局决定舞台高度。内容裁剪；必要时使用定位的内部舞台，防止大图撑开布局。
- 图片导入和替换操作靠近画布。查看控件独立浮动：边界和跟随主题的棋盘格／纯色背景仅影响查看，有内容时显示。
- 多画布保持独立查看变换。点九图源图视图、拉伸预览视图和 HUD 几何分别重置。背景变化不得影响导出结果。

## 主题、元数据与验证

保留持久化的 `web-tools:theme` 偏好（`system`、`light`、`dark`）、实时系统主题变化以及 React 前执行的首屏脚本。通过 `ClientOnly` 在水合后显示已存偏好。

保留 SSG 路由 ID 与水合数据、逐页 `Seo`、旧 URL／二维码重定向（含查询与 hash 内容）、隐藏工具直达路由、未知路由兜底、manifest／图标引用和 Safari 网页应用元数据。

改动后执行 `pnpm lint`、`pnpm typecheck` 和 `pnpm build`。在真实产品页检查亮暗主题、紧凑桌面与手机布局、键盘焦点、菜单／弹窗层级及单树水合。画布专属验收属于各工具迁移；源码检查或原型覆盖不能代替浏览器证据。原生 Safari 独立窗口启动需要单独在设备或应用中检查。
