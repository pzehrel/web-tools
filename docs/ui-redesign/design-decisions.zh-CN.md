# UI 重设计决策

这些决定汇总于 2026-10-20 完成的评审，保留已确认的范围和理由，不表示当前实现状态。详细契约和后续证据见[历史实施规格](implementation-spec.zh-CN.md)、[GitHub 规格及讨论](https://github.com/pzehrel/web-tools/issues/1)、[现行设计规范](../DESIGN.zh-CN.md)和[生产验收记录](../ui-redesign-acceptance.zh-CN.md)。[English](design-decisions.md)。

## 用户与设备

- 优先服务开发与设计中的高频任务。导入、调参、预览、导出应易于访问，首次使用的说明就近放在对应控件旁。
- 使用 URL 编辑与二维码结果、点九图参数与画布、多帧导入／排序／预览／导出作为可比较的设计任务。
- 桌面浏览器是主要工作台。手机保留导入、基本参数、预览和导出。精细切片与多帧排序优先优化桌面，不删除既有手机能力。

## 公开范围与导航

- 首页和工具切换菜单展示 URL 与二维码、帧动画、Lottie 预览、点九图。工具页提供返回与切换操作，中文导航统一使用“URL 与二维码”。
- CSS 扫光与字体工具箱暂缓，导航入口隐藏；既有直达路由和能力继续保留。
- 保留现有处理引擎、存储记录、路由兼容和 SSG 水合。本次重设计不增加后端、账号、云同步或桌面封装。

## 已评审界面

- 采用已评审的 F 方向：紧凑控件、默认可见画布、浮动任务面板、亮暗语义色和无描边图标操作。蓝色为主色、浅蓝为次色，绿／红／琥珀／青蓝分别区分成功／失败／警告／提示。
- URL 输入与二维码同排等高，递归参数树与记录各占整行。保留递归编辑器，不新增平面解析摘要。
- 帧动画序列全宽置底，短播放／进度控件位于其上方。Lottie 使用窄左栏任务标签与独立图集视图。点九图保留高频中心裁剪及可移动、调整大小的预览 HUD。
- 保留两个二维码直接导出入口：页面导出纯二维码，URL 放大预览导出组合图，纯文本回退为纯二维码。移除下载下拉菜单（U17）。
- 移除随播放变化的缩略图高亮与自动跟随（F06），保留选择、焦点、重排、暂停／定位和进度指示。
- 界面文案不强调数据位置或上传行为。这一文案决定不改变处理机制或兼容要求。

## 证据与保留资料

[功能基线](README.zh-CN.md)与[原型映射](prototype-current.zh-CN.md)保留行为 ID 和带日期的评审边界。原型缺失不缩小已确认的功能范围。设计认可、源码核查和编译通过，与生产浏览器验收相互区分。

仓库保留规格、决策、功能清单和带日期的验证报告，不再保留临时截图、导出样本、原型源码副本、补丁和迁移中间文件。引用这些产物的历史检查描述过去的运行，仅靠保留文档无法复现。[URL 评审](url-review.zh-CN.md)记录了一版被否定的布局，以上已确认布局优先。
