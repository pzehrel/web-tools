## 运行边界

生产路由、样式、存储和 Vite 配置沿用已完成的重设计。原来位于 `apps/web/src` 的原型文件保存在源码快照中，不放回 TypeScript 应用。待提交的根代理说明补丁也保存在快照中；生效的根代理说明沿用生产基线。`.scratch` 是不可变的历史输入，不参与 lint；生产代码的 lint、类型检查、测试和 SSG 构建继续启用。

快照记录相对指定基线的增量，不是独立可运行的应用。需要重建历史工作时，在该基线的独立检出中使用清单的路径映射恢复文件。旧覆盖结果、脚本和截图不能替代当前生产验收。
