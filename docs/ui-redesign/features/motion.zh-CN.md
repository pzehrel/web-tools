状态：`covered` = 原型覆盖该行能力（并非运行验收通过）；`partial` = 仅覆盖部分或行为有缩水；`missing` = F 无对应能力；`legacy-only` = F 入口进入现有页面，该能力可用但尚未重设计。

## 边界与验证

- 帧动画现有下载格式只有 PNG 精灵图；CSS/Less/SCSS 是可复制样式代码。记录内部 ZIP 是存储实现，不是用户 ZIP 导出功能。没有将 GIF/WebM/APNG 动画导出列为已有功能。
- 帧序列拖排源码使用 HTML drag events；没有确认手机原生触摸拖排可用，不把这一点写成已验收。触屏画布平移/捏合在共享 hook 中有实现。
- 现有帧动画对单图解码失败会过滤，没有专门逐文件失败消息；不能误写成已实现的详尽错误报告。现有 Lottie ZIP 导出仅在有图集结果时可用，不声称支持关闭优化后的原包下载。
- 本文证据为源码；新 UI 的完整验收仍须实际覆盖文件导入、真实输出、记录恢复、鼠标/触屏与亮暗主题。
