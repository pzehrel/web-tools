# Hidden tool feature baseline and F prototype coverage

> **Historical audit snapshot:** Coverage states and gaps below were recorded before the full-function expansion and do not describe the current F. Existing behavior and preservation criteria remain valid. See the [current full-function prototype](../prototype-current.md) for the latest per-ID UI mapping and validation boundaries.
> [Baseline index](../README.md) · [简体中文](hidden.zh-CN.md)

Source audit of the current working tree on 2026-10-18. This inventories user-visible behavior, not every engine API. It is not a complete browser, font-format, export-fidelity, or accessibility test. All listed capabilities are retention requirements for the UI redesign; preserving a capability does not require retaining its old layout or implementation defect. Do not expose hidden tools on the homepage without a separate decision.

Both tools have `status: 'hidden'` in [the registry](../../../apps/web/src/tools/index.ts#L57), while [the route table](../../../apps/web/src/main.tsx#L39) exposes `/tools/css-shine` and `/tools/font-toolkit`. F covers neither tool: [the development gate](../../../apps/web/src/root-layout.tsx#L12) intercepts any `variant` query, and [the prototype pathname mapping](../../../apps/web/src/ui-redesign.prototype.tsx#L431) maps these paths to its homepage. A working original route is not redesigned coverage.

Every row below therefore has status **Not covered**. Acceptance points describe retained behavior to verify in the future redesign, not checks already performed.

## Boundaries and audit checks

- C01–C09 and T01–T16 are absent from F, not partially redesigned just because the original pages remain routable.
- Font-engine APIs accept `FontFormat` including OTF output and compute additional metadata; only UI-exposed paths count above. This audit does not add OTF export, metadata editors, variable-axis controls, font collections, multi-font comparison, glyph editing, batch workflows, or API capabilities the interface does not expose.
- The existing font page contains local-processing explanatory text. It is copy, not a capability-retention requirement: the user's instruction to make no such emphasis remains applicable to the redesign.
- Source files for both tools, font engine, charset data, tool registry, routes, development gate, and F pathname mapping were read. A script checked unique tier sizes (3,000 / 5,000 / 7,000). No production/prototype source was changed and no full interactive test was run for these two tools.
