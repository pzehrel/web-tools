## 范围排除

- 既有关于本地处理、数据位置或不上传的宣传属于文案，不是受保护能力。用户要求不再强调这些内容，继续有效。
- 当前前端即使配置服务器地址仍选择 IndexedDB。HTTP 存储、账号 UI、云同步不是本轮要保留的已实现前端功能；服务器工作不在本次重设计范围内。
- 不固定旧布局的像素、颜色、卡片样式或标签原文。输入／输出语义、能力、状态变化、操作可访问性和兼容性构成功能基线。
