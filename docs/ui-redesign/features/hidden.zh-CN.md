## 边界与审计检查

- C01–C09 和 T01–T16 在 F 中均未覆盖，不会因原有页面可路由访问而成为部分重设计。
- 字体引擎 API 接受包含 OTF 输出的 `FontFormat`，也计算更多元数据；上表仅统计 UI 暴露路径。本审计不增加 OTF 导出、元数据编辑器、可变轴控件、字体集合、多字体对比、字形编辑、批处理或界面未暴露的 API 能力。
- 现有字体页面有本地处理说明。它属于文案，不是必须保留的功能；用户“不做此类强调”的要求仍适用于重设计。
- 已读取两个工具、字体引擎、字符集、工具注册表、路由、开发入口和 F 路径映射源码；脚本核对了等级唯一字符数（3,000／5,000／7,000）。未修改产品／原型源码，也未对这两个工具开展完整交互实测。
