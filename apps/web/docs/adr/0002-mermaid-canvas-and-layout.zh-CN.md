# Mermaid 画布与布局边界

于 2026-10-22 为规划中的首版接受，尚待实现和原型验证。所选路线使用 React Flow 实现编辑画布、ELK 实现自动布局、Mermaid 实现代码预览，手动几何信息与源码语义分开保留。这样可以支持交互优先的定位操作，同时不宣称标准 Mermaid 代码或其预览会重现编辑器坐标；自动布局在首次导入支持的代码时执行，此后通过用户明确操作触发，普通编辑则尽量保留已有位置。

完整契约和验证要求记录在 [Mermaid 编辑器：选择画布技术与布局保留策略](https://github.com/pzehrel/web-tools/issues/20) 中。依赖的具体版本、复杂分组路由、Safari 行为和性能仍需原型证据；验证不通过时需要重新评估路线，不能静默缩减已接受的功能范围。先前的[源码与历史决策](0001-mermaid-source-and-history.zh-CN.md)继续有效，工程文件格式和导出集合仍是独立决策。
