# Mermaid 当前代码与文档历史

于 2026-10-22 为规划中的首版接受，尚待实现。Mermaid 编辑器以当前代码（含错误草稿）作为权威源文本，单独保留导入原稿，并从通过校验的版本派生图模型和预览状态。代码与画布编辑共用一条文档历史，允许画布修改统一源码排版，同时保留图的含义和全部普通注释；这一取舍以修改后文本的精确排版，换取交互优先且原稿可恢复的建图体验，而不维护可独立编辑的源码历史与图历史。

完整契约、用户确认和待验证问题记录在 [Mermaid 编辑器：确定源码、图模型与撤销历史的同步规则](https://github.com/pzehrel/web-tools/issues/19) 中。本记录不选择解析器、画布引擎、序列化格式或持久化策略。
