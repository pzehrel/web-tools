**主要需求:** L01–L09、L19–L20、D10；落实 D01–D02。建立 D09 的任务标签布局，在 08 完成迁移前保留现有优化、资源对比、导出与记录入口。

## 验收条件

- [ ] 单 ZIP 或完整目录且恰好一个有效 data.json；嵌套／相对／内嵌图片解析，缺失／不可读警告，不自动抓取远程图片。
- [ ] 保留替换／示例／清空重置、两个库、canvas／SVG、meet／slice、小数进度、速度／方向／循环和主舞台手势。
- [ ] 统一导入／元信息／视图控件，缩短播放条；素材消息位于左栏底部，警告／错误按规则展开且手机可达。
- [ ] 验证换行、触摸和可滚动消息，不只验证成功导入。

## 需求验收清单

- [ ] **L01** — 作为设计者，我希望通过单个 ZIP 或完整目录导入项目，保留路径且要求恰有一个有效 data.json，以便支持的项目打包方式明确。
- [ ] **L02** — 作为设计者，我希望按现有格式解析嵌套／预合成、相对路径和内嵌图片引用，并提示缺失／不可读素材，以便项目资源正确且不自动获取远程图片。
- [ ] **L03** — 作为设计者，我希望示例、替换和清空重置项目相关的优化、播放与查看状态，以便项目之间不泄漏状态。
- [ ] **L04** — 作为设计者，我希望保留两种既有 Lottie 渲染库及 canvas／SVG 渲染器，以便比较受支持的引擎。
- [ ] **L05** — 作为设计者，我希望选择完整显示和铺满裁切，以便动画适合目标查看区域。
- [ ] **L06** — 作为设计者，我希望播放、暂停及小数帧定位保留当前／总帧和项目元数据，以便精确检查动画时序。
- [ ] **L07** — 作为设计者，我希望保留既有速度挡位、方向和循环，以便灵活检查播放。
- [ ] **L08** — 作为设计者，我希望主画布自动适配，并独立支持缩放／捏合、平移、倍率反馈和重置，以便检查完整动画。
- [ ] **L09** — 作为设计者，我希望动画和图集都支持边界与随主题变化的棋盘／纯色背景，以便看清透明素材。
- [ ] **L19** — 作为设计者，我希望看到可滚动的错误／警告、缺失素材详情、操作／引擎失败，以及忙碌／空白／禁用状态，以便理解问题并恢复。
- [ ] **L20** — 作为手机用户，我希望能访问堆叠或标签式控件、换行动作、双画布触屏手势及可滚动消息，以便完成 Lottie 核心任务。
- [ ] **D10** — 作为 Lottie 用户，我希望使用窄左栏、短播放控件和独立浮动图集预览，以便动画仍是主要工作区。
