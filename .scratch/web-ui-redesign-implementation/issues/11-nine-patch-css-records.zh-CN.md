## 验收条件

- [ ] 紧凑四边值、图片路径提示、宽度／外扩／填充／重复轴、复制成功和仅代码全选。
- [ ] 恢复来源字节与切线／渲染／裁剪／代码写法，完成归一化并显示记录名称／体积；空白时禁用保存。
- [ ] 单条删除保留当前编辑器及其他记录。
- [ ] HUD／视图几何不存入记录或输出。
- [ ] 10 不阻塞本票：现有裁剪参数与持久契约始终可用；12 验证最终界面的组合行为。

## 需求验收清单

- [ ] **N24** — 作为开发者，我希望生成分开写／简写 CSS，合并四边值并提供可替换图片路径、有效宽度、填充、外扩及双轴重复，以便复用样式。
- [ ] **N25** — 作为开发者，我希望复制 CSS 后短暂显示成功标识，以便明确剪贴板操作结果。
- [ ] **N26** — 作为开发者，我希望代码可聚焦和选择，Command／Control+A 仅选择代码，并有图片路径提示，以便不把选择扩散到整页。
- [ ] **N27** — 作为回访用户，我希望明确持久保存源图字节及全部切片／渲染／裁剪／代码写法设置，无图时禁止保存，以便项目内容完整。
- [ ] **N28** — 作为回访用户，我希望记录保留命名回退、字节大小显示，并规范化恢复当前及旧版不完整记录与图片，以便已保存工作可用。
- [ ] **N29** — 作为回访用户，我希望删除单条记录只刷新对应列表项，保留其他记录与当前编辑，以便删除范围明确。
