**交付内容:** 导入图片、ZIP 或目录，在底部全宽序列中排序和勾选，裁剪共同透明边，并在清空或更换素材时保留序列规则。

**主要需求:** F01–F07、F19。建立 D07 的帧序列部分；05 补齐并验证进度条与序列的位置关系。

## 验收条件

- [ ] 有效图片过滤、归档过滤、来源信息、新批次自然排序追加和显式全局排序；后续导入不改变已有手动顺序。
- [ ] 验证前后拖排、全选／全不选／逐帧选择、稳定选择反馈且不跟随播放高亮、叠加裁剪预览、实时 alpha 边界、尺寸不同警告、取消／应用和结果像素。
- [ ] 清空停止播放并重置依赖状态。
- [ ] 现有播放／导出／记录操作仍可访问。

## 需求验收清单

- [ ] **F01** — 作为设计者，我希望通过选择或画布拖放导入多张浏览器可解码图片，并跳过无效图片，以便有效帧仍可使用。
- [ ] **F02** — 作为设计者，我希望 ZIP 与目录导入保留现有支持格式、源文件名和归档过滤，以便加载已有素材集合。
- [ ] **F03** — 作为设计者，我希望新批次按自然文件名顺序追加，同时保留既有手动顺序，并可主动全局排序，以便自主组织序列。
- [ ] **F04** — 作为设计者，我希望明确载入示例，以便无需提供文件也可预览与导出。
- [ ] **F05** — 作为设计者，我希望逐帧、全选／全不选控制预览、播放和导出，但不删除素材，以便可逆地调整参与帧。
- [ ] **F06** — 作为设计者，我希望保留缩略图、文件名、原尺寸／字节数、前后拖排与稳定的选中反馈，以便整理帧时不受播放高亮干扰。
- [ ] **F07** — 作为设计者，我希望共同透明边裁剪包含叠放预览、边界、实时 alpha 控制、混合尺寸警告、取消／应用和结果反馈，以便有依据地裁剪。
- [ ] **F19** — 作为设计者，我希望清空素材停止播放，并重置相关勾选、范围、裁剪与导入反馈，以便干净地开始下个项目。
