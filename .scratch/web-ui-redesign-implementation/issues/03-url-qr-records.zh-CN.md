# 03: URL 二维码输入、直接下载与持久记录

**交付内容:** 生成或识别二维码，查看放大后的树预览，直接下载对应图片，保存／更新／预览记录，并在刷新后恢复旧工作。

**Blocked by:** [02 — URL 递归编辑与分享链接往返](02-url-tree-sharing.zh-CN.md)

**Status:** ready-for-agent

**Labels:** ready-for-agent

**Approval:** 2026-10-20 — human user: 可以

依据：[完整规格](../spec.zh-CN.md)；[来源索引](../sources.zh-CN.md)；[任务索引](../tickets.zh-CN.md)；[英文原文](03-url-qr-records.md)。

**主要需求:** U11–U23。

## 验收条件

- [ ] 防抖、过期结果保护、选择／拖入／粘贴的输入保护和不同识别错误；页面下载纯二维码，弹窗下载二维码加参数，纯文本回退纯二维码，无下拉菜单。
- [ ] 解码二维码，检查组合图尺寸／换行／省略及重试／忙碌行为。
- [ ] 验证新保存与显式更新、命名／重命名、选择前预览、取消选择、复制、确认删除／清空及选择清理。
- [ ] 保留 URL 原存储标识、旧数据转换和读取失败不阻塞操作。

## 需求验收清单

- [ ] **U11** — 作为工具用户，我希望 URL 或纯文本在防抖后生成现有二维码 PNG，忽略过期结果并正确响应清空，以便二维码对应当前内容。
- [ ] **U12** — 作为工具用户，我希望选择图片、拖入二维码区、在文本输入外粘贴图片都能识别二维码，并支持重复选择同一文件，以便全部既有识别路径可用。
- [ ] **U13** — 作为工具用户，我希望区分图片不可读与未发现二维码，失败不破坏当前文本，并获得纯文本树说明，以便从不合适的输入中恢复。
- [ ] **U14** — 作为工具用户，我希望点击二维码图片打开包含只读参数树的放大预览，并可通过 Escape／遮罩关闭，以便检查结果。
- [ ] **U15** — 作为工具用户，我希望页面下载操作直接下载纯二维码 PNG，以便一次操作完成常用导出。
- [ ] **U16** — 作为工具用户，我希望放大预览的下载操作对 URL 内容直接生成现有二维码与参数图，以便分享完整结构化结果。
- [ ] **U17** — 作为工具用户，我希望直接导出保留可用性判断、忙碌保护、错误反馈与纯文本二维码回退，并取消下拉菜单，以便已评审下载流程可靠。
- [ ] **U18** — 作为回访用户，我希望保存新增有名快照，更新选中记录需明确操作，以便打字不静默覆盖已保存内容。
- [ ] **U19** — 作为回访用户，我希望保留默认记录名回退与 Enter／失焦／Escape 重命名语义，以便命名行为可预期。
- [ ] **U20** — 作为回访用户，我希望选中记录载入输入，再次选中则取消选择而不覆盖输入，以便选择与编辑相互区分。
- [ ] **U21** — 作为回访用户，我希望桌面记录提示与手机预览弹窗显示二维码／树或纯文本，以便选择前检查记录。
- [ ] **U22** — 作为回访用户，我希望复制记录、确认单条删除、确认全部清空，并正确清理选中状态，以便记录管理完整。
- [ ] **U23** — 作为回访用户，我希望持久记录和旧 URL／二维码记录继续在原存储身份下恢复，读取失败不阻断工具，以便升级后保留工作。
