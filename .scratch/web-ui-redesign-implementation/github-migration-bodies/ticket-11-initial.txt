# 11: Nine-patch CSS reuse and durable project recovery

**What to build:** Copy accurate longhand/shorthand CSS and save, reload or delete complete nine-patch projects, including older incomplete records.

**Blocked by:** [09 — Nine-patch slicing, rendering and independent preview HUD](09-nine-patch-editor-hud.md)

**Status:** ready-for-agent

**Labels:** ready-for-agent

**Approval:** 2026-10-20 — human user: 可以

Context: [full specification](../spec.md); [source index](../sources.md); [ticket index](../tickets.md); [Chinese translation](11-nine-patch-css-records.zh-CN.md).

**Primary requirements:** N24–N29.

## Acceptance criteria

- [ ] Compact four-side values, image path guidance, widths/outset/fill/repeat axes, copy success and code-only select-all.
- [ ] Restore original source bytes plus slice/render/crop/code-writing settings with normalization and record names/sizes; empty save is disabled.
- [ ] Targeted deletion preserves the current editor and other records.
- [ ] HUD/view geometry is not stored or exported.
- [ ] Ticket 10 is not a blocker: existing crop parameters and durable contracts remain usable throughout; ticket 12 verifies their combined finished interfaces.

## Requirement acceptance checklist

- [ ] **N24** — As a developer, I want longhand/shorthand CSS with compact four-side values, a replaceable image path, valid widths, fill, outset and repeat axes, so that the styling is ready to reuse.
- [ ] **N25** — As a developer, I want CSS copying with a temporary success indication, so that clipboard actions are clear.
- [ ] **N26** — As a developer, I want focusable/selectable code with code-only Command/Control+A and image-path guidance, so that code selection does not spread to the whole page.
- [ ] **N27** — As a returning user, I want explicit durable saving of source bytes and all current slice/render/crop/code-writing settings with save disabled when empty, so that projects are complete.
- [ ] **N28** — As a returning user, I want named record fallback, byte-size display and normalized restoration of current/older incomplete records and images, so that saved work remains usable.
- [ ] **N29** — As a returning user, I want single-record deletion to refresh only that record's list entry while preserving other records and the current editor, so that deletion remains targeted.
