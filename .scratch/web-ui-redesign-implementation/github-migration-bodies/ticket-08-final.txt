**Primary requirements:** L10–L18, D09. Completes atlas behavior in D10 and all related L19–L20 states.

## Acceptance criteria

- [ ] Optimization/playback/project-record tabs with comparison and export always reachable.
- [ ] Retain every packing option/default/bound, rebuild toggle and valid-original fallback, animated-image exclusions, increases and detailed metrics.
- [ ] Inspect multiple atlases with independent gestures/reset.
- [ ] Unzip output to verify rewritten references, atlas PNGs and required original/embedded assets.
- [ ] Verify named durable complete projects and settings, old-record compatibility, load/delete and asynchronous failure recovery.
- [ ] Reuse asset, animation-detection, metrics and record-archive tests; no new optimizer or storage format is required.

## Requirement acceptance checklist

- [ ] **L10** — As a designer, I want optimization toggling and automatic rebuilding after option changes, with original assets used while rebuilding or disabled, so that the preview represents a valid current state.
- [ ] **L11** — As a designer, I want the existing maximum atlas sizes, padding and extrusion settings with their defaults and bounds, so that packing controls remain complete.
- [ ] **L12** — As a designer, I want rotation, transparent trimming with animation-position preservation and identical-pixel merging, so that existing optimization choices remain available.
- [ ] **L13** — As a designer, I want advanced power-of-two, square-atlas and alpha-threshold controls, so that detailed atlas constraints remain adjustable.
- [ ] **L14** — As a designer, I want supported animated image resources detected, excluded from atlas packing and explained, so that optimization does not flatten animation.
- [ ] **L15** — As a designer, I want before/after bytes, texture counts, pixels and estimated RGBA memory with increases identified, plus atlas occupancy and deduplication statistics, so that I can assess actual results.
- [ ] **L16** — As a designer, I want single/multiple atlas viewing with independent fitting, zoom/pinch, pan, scale feedback, boundaries and reset, so that atlas inspection does not disturb the main animation.
- [ ] **L17** — As a designer, I want the existing optimized ZIP with rewritten data.json, numbered atlas PNGs and required original non-optimizable assets, so that exported projects remain usable.
- [ ] **L18** — As a returning user, I want named durable complete projects restoring optimization, library, renderer, loop, speed, direction and fitting settings, with load/delete actions, so that inspection can resume.
- [ ] **D09** — As a Lottie user, I want atlas optimization, playback settings and project-record tabs with persistent resource comparison and export, so that I can switch tasks without losing the result context.
