# 09: 点九图切线、渲染与独立预览 HUD

## 验收条件

- [ ] 导入取消／类型／解码恢复，示例／默认值／清空正常路径，不交叉切线归一化及单独切线重置。
- [ ] 保留绑定／解绑宽度、外扩、填充和双轴重复。
- [ ] 验证八个内部逻辑尺寸手柄与八个 HUD 外部手柄、独立尺寸／位置、键盘步长、缩放换算、对边固定、视口边界和指针清理。
- [ ] 来源／预览／HUD 重置独立，适配／手动接管和仅查看背景有效。
- [ ] 中心裁剪保持靠上，迁移期间原输出／记录可用。

## 需求验收清单

- [ ] **N01** — 作为设计者，我希望通过选择图片或拖入首个文件开始编辑，并显示名称和源尺寸，以便对预期图片切片。
- [ ] **N02** — 作为设计者，我希望取消选择保留当前图片、区分类型与解码错误、有效替换清除错误，以便导入恢复可预期。
- [ ] **N03** — 作为设计者，我希望生成示例走正常载入／默认参数流程，以便示例反映真实工作方式。
- [ ] **N04** — 作为设计者，我希望替换图片时恢复既有的图像推导切片／宽度、外扩与裁剪默认值并重新适配源图，以便旧几何不破坏新图。
- [ ] **N05** — 作为设计者，我希望清除图片回到导入态并移除导入／裁剪反馈，以便工作区一致地重置。
- [ ] **N06** — 作为设计者，我希望四边切片以非负整数源像素表示，并根据对边与恢复后尺寸规范化，以便切线不能交叉。
- [ ] **N07** — 作为设计者，我希望切线拖动通过指针捕获、当前缩放换算源像素并处理结束／取消，以便数值与切线同步。
- [ ] **N08** — 作为键盘用户，我希望切线是具有范围的可聚焦 slider，支持方向键 1 像素／Shift 10 像素调整，以便不依赖拖动也能精确切片。
- [ ] **N09** — 作为设计者，我希望切片重置恢复图像推导默认值而不改无关参数，以便局部重置安全。
- [ ] **N11** — 作为设计者，我希望可绑定宽度、独立编辑解绑宽度并重新绑定，以便渲染宽度与源切片相互区分。
- [ ] **N12** — 作为设计者，我希望既有整数外扩设置作用于预览与 CSS，以便调整边框外部扩展。
- [ ] **N13** — 作为设计者，我希望中心填充保留明确设置与既有默认值，以便预览和 CSS 一致。
- [ ] **N14** — 作为设计者，我希望横纵分别选择 stretch／repeat／round／space，以便预览与 CSS 保留两个重复轴。
- [ ] **N18** — 作为设计者，我希望独立实时 border-image 预览体现切片、宽度、外扩、填充和双轴重复并显示尺寸，以便检查输出行为。
- [ ] **N19** — 作为设计者，我希望保留八向逻辑预览缩边、既有角点键盘步长、考虑缩放的位移和固定对侧锚点，以便精确测试拉伸。
- [ ] **N20** — 作为设计者，我希望源图支持平移、滚轮／触控板／触屏缩放及短暂倍率反馈，且不改变导出数据，以便查看与编辑分离。
- [ ] **N21** — 作为设计者，我希望预览的查看和重置独立，并有缩边／平移保护与补偿清理，以便预览手势可预期。
- [ ] **N22** — 作为设计者，我希望两个舞台初始适配，在手动接管前随可用尺寸变化，替换／重置后恢复适配，以便内容始终可达。
- [ ] **N23** — 作为设计者，我希望源图／预览的边界与既有六组随主题变化的棋盘／纯色配色仅影响查看，以便导出保留原图数据。
- [ ] **D11** — 作为点九图用户，我希望中心裁剪靠上，并可移动和调整拉伸预览 HUD 的大小，以便方便地执行高频裁剪和预览比较。
- [ ] **D12** — 作为点九图用户，我希望分别重置源图视图、预览视图和 HUD，以便恢复查看状态不会意外改变输出参数。
