# 04: Frame import, full-width sequence and common-edge crop

**What to build:** Import images, ZIP or directory, organize and select the full-width bottom sequence, crop shared transparent edges and clear or replace materials without losing sequence rules.

**Blocked by:** [01 — Home, navigation and production themes](https://github.com/pzehrel/web-tools/issues/2)

**Status:** ready-for-agent

**Labels:** ready-for-agent

**Approval:** 2026-10-20 — human user: 可以

Context: [full specification](https://github.com/pzehrel/web-tools/issues/1); [source index](https://github.com/pzehrel/web-tools/issues/1#issuecomment-6285080234); [ticket index](https://github.com/pzehrel/web-tools/issues/1#implementation-tickets); [Chinese translation](https://github.com/pzehrel/web-tools/issues/5#issuecomment-6285084105).

**Primary requirements:** F01–F07, F19. Introduces the sequence portion of D07; ticket 05 completes and verifies the progress/sequence arrangement.

## Acceptance criteria

- [ ] Valid-image filtering, archive filtering, source metadata, naturally sorted appended batches and explicit global sort; manual order survives later imports.
- [ ] Verify before/after drag, all/none and per-frame selection, stable selection feedback with no playback-following highlight, stacked crop preview, live alpha limits, mixed-size warning, cancel/apply and result pixels.
- [ ] Clearing stops playback and resets dependent states.
- [ ] Existing playback/export/record actions remain reachable.

## Requirement acceptance checklist

- [ ] **F01** — As a designer, I want multiple browser-decodable images imported through selection or canvas dropping while invalid images are skipped, so that valid frames remain usable.
- [ ] **F02** — As a designer, I want ZIP and directory image imports with the current supported formats, source names and archive filtering, so that I can load existing asset collections.
- [ ] **F03** — As a designer, I want new batches appended in natural filename order while manual existing order stays intact, plus explicit global sorting, so that sequence organization remains under my control.
- [ ] **F04** — As a designer, I want an explicit example action, so that I can preview and export without supplying files.
- [ ] **F05** — As a designer, I want per-frame and all/none selection to control preview, playback and exports without deleting materials, so that I can adjust participation reversibly.
- [ ] **F06** — As a designer, I want thumbnails, filenames, original dimensions/bytes and before/after drag sorting with stable selection feedback, so that I can organize frames without playback-driven highlighting.
- [ ] **F07** — As a designer, I want common-transparent-edge cropping with stacked preview, bounds, live alpha controls, mixed-size warnings, cancel/apply and result feedback, so that I can crop deliberately.
- [ ] **F19** — As a designer, I want clearing materials to stop playback and reset dependent selection, range, crop and import feedback, so that the next project starts cleanly.
