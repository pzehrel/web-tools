## 需求验收清单

- [ ] **N10** — 作为设计者，我希望自动像素分析生成规范化切片、宽度和最小中心裁剪设置，并提供忙碌／结果／错误反馈，以便采用或手工修正识别结果。
- [ ] **N15** — 作为设计者，我希望中心裁剪支持两轴／X／Y、受限的正整数保留尺寸与最小裁剪，以便高频裁剪功能完整。
- [ ] **N16** — 作为设计者，我希望看到保留中心与删除行列遮罩、可访问的说明及平铺警告，以便下载前看清裁剪后果。
- [ ] **N17** — 作为设计者，我希望裁剪 PNG 按 1:1 保留所选像素，尺寸／命名／可用性正确，以便不缩放图片或改变 CSS 切片值。
