# 10: Nine-patch automatic analysis, center crop and pixel export

**What to build:** Analyze slices automatically, refine frequent center cropping with visible kept/removed areas and download the precise cropped PNG.

**Blocked by:** [09 — Nine-patch slicing, rendering and independent preview HUD](https://github.com/pzehrel/web-tools/issues/10)

**Status:** ready-for-agent

**Labels:** ready-for-agent

**Approval:** 2026-10-20 — human user: 可以

Context: [full specification](https://github.com/pzehrel/web-tools/issues/1); [source index](https://github.com/pzehrel/web-tools/issues/1#issuecomment-6285080234); [ticket index](https://github.com/pzehrel/web-tools/issues/1#implementation-tickets); [Chinese translation](https://github.com/pzehrel/web-tools/issues/11#issuecomment-6285087634).

**Primary requirements:** N10, N15–N17; completes the center-crop portion of D11.

## Acceptance criteria

- [ ] Analysis normalizes slices/widths/minimum crop, reports busy/result/error and permits manual refinement.
- [ ] Both/X/Y axes, bounded retained dimensions, minimum action, overlay explanations and repeat warnings remain.
- [ ] Decode exported PNG to verify 1:1 corners/retained rows/columns, dimensions and naming; disable ineffective crop, preserve numeric CSS slices and keep live border-image preview based on the original source.

## Requirement acceptance checklist

- [ ] **N10** — As a designer, I want automatic pixel analysis to produce normalized slices, widths and minimum center-crop settings with busy/result/error feedback, so that I can accept or manually refine detection.
- [ ] **N15** — As a designer, I want center cropping with both/X/Y axes, bounded positive retained dimensions and minimum cropping, so that frequent cropping remains complete.
- [ ] **N16** — As a designer, I want retained-center and removed-row/column overlays with accessible explanations and tiling warnings, so that cropping consequences are visible before download.
- [ ] **N17** — As a designer, I want the cropped PNG to preserve selected pixels at 1:1 with correct dimensions/name and availability, so that cropping does not rescale or alter CSS slice values.
