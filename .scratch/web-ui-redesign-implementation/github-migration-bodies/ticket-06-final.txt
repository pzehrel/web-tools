## Acceptance criteria

- [ ] Linked grid controls, actual output preview/metrics, source-max cell dimensions and centered smaller frames; inspect exported pixels.
- [ ] Generated code preserves selected range, timing, direction, loops, pixel style, variables and relative sizing, with copy feedback and code-only select-all.
- [ ] Verify archived bytes/order/selection/crop threshold/playback/export settings, naming/load/delete, older records and empty/busy/failure recovery using existing archive tests and real-page workflows.

## Requirement acceptance checklist

- [ ] **F15** — As a designer, I want a PNG sprite sheet using original maximum cell dimensions with smaller frames centered and linked row/column controls, so that exported pixels and layout remain correct.
- [ ] **F16** — As a designer, I want live sprite preview, frame/cell/grid/output measurements and empty/busy states, so that I can inspect the actual export arrangement.
- [ ] **F17** — As a developer, I want CSS/Less/SCSS output, variable and relative-size options, matching direction/loops/timing/pixel style, copy feedback and code-only select-all, so that the generated animation is reusable.
- [ ] **F18** — As a returning user, I want named durable projects restoring bytes, order, selection, range, playback, crop threshold and export settings, with load/delete actions, so that work resumes accurately.
- [ ] **F20** — As a designer, I want empty-selection, archive/import, crop, export and copying feedback with appropriate busy/disabled states, so that failures and unavailable actions are understandable.
