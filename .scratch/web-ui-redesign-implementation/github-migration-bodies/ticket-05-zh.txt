# 05: 帧播放、独立进度与画布查看

**交付内容:** 在默认可见的画布检查已选帧，通过序列上方的短进度条定位，设置时长／范围／方向／循环，并按预期恢复播放。

## 验收条件

- [ ] 窄左栏止于底部全宽序列上方，收起序列释放画布空间。
- [ ] 定位暂停但不改变选择或导出／播放范围；继续播放遵守范围，有限循环结束后可正确重播。
- [ ] 验证逐帧、缩略图定位、带输入保护的快捷键、FPS／时长／小数推算、包含端点的范围约束、正向／反向／往返、适配／平移／双指缩放／重置、仅影响查看的背景／边界和像素渲染。
- [ ] 复用舞台测试并验证真实页面。

## 需求验收清单

- [ ] **F08** — 作为设计者，我希望保留播放、暂停、步进、已选缩略图定位和既有快捷键，并保护文本输入、支持 Escape 关闭裁剪弹窗，以便高效操作。
- [ ] **F09** — 作为设计者，我希望保留 FPS 与时长关系、小数反推和时间信息，以便预览与导出的时序一致。
- [ ] **F10** — 作为设计者，我希望使用含端点的起止范围、完整范围重置和随勾选收敛的范围，以便播放与导出使用预期帧。
- [ ] **F11** — 作为设计者，我希望正序、倒序、往返支持无限或有限循环，并在结束后可重播，以便播放和代码保留选定行为。
- [ ] **F12** — 作为设计者，我希望自动按源尺寸适配，并支持缩放／捏合、平移、倍率反馈与重置，以便检查大小不同的帧。
- [ ] **F13** — 作为设计者，我希望使用边界与随主题变化的棋盘／纯色查看背景，以便检查透明度且不改变输出像素。
- [ ] **F14** — 作为设计者，我希望像素风设置作用于预览和生成样式，以便像素素材保留预期渲染效果。
- [ ] **D07** — 作为帧动画用户，我希望帧序列横贯整个底部，短进度控件紧邻其上，以便保留有用的画布空间。
- [ ] **D08** — 作为帧动画用户，我希望进度定位独立于缩略图选择，且缩略图不随播放高亮，以便序列编辑保持视觉稳定。
