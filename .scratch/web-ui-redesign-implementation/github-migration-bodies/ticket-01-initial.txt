# 01: Home, navigation and production themes

**What to build:** Enter any public tool from the reviewed compact home, return on the left, switch tools, open the correct GitHub link and retain system/light/dark preferences on real routes.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Labels:** ready-for-agent

**Approval:** 2026-10-20 — human user: 可以

Context: [full specification](../spec.md); [source index](../sources.md); [ticket index](../tickets.md); [Chinese translation](01-home-navigation-themes.zh-CN.md).

**Primary requirements:** G01–G05, G08–G09, D01–D04. Canvas-specific adoption of D01–D02 is also required in tickets 05, 07 and 09.

## Acceptance criteria

- [ ] Four public entries only; retained redirects, hidden direct routes and fallback; correct menu/modal stacking; equal square theme controls; production blue/semantic palette without a development gate; readable feedback and focus; single hydrated page with correct metadata, manifest and Safari behavior.
- [ ] Reconcile production design guidance with approved decisions.
- [ ] Existing tool functionality remains usable while its workspace awaits migration.

## Requirement acceptance checklist

- [ ] **G01** — As a frequent user, I want the home to show the four ready public tools, so that I can enter my task directly and hidden tools stay hidden.
- [ ] **G02** — As a returning user, I want current routes, legacy URL/QR redirects, hidden direct routes and unknown-address fallback to keep working, so that existing links remain useful.
- [ ] **G03** — As a tool user, I want a discoverable return-home action on the left and a public-tool switcher, so that navigation does not consume a permanent sidebar.
- [ ] **G04** — As a tool user, I want system, light and dark preferences to persist, respond to system changes and apply before first paint, so that theme behavior remains consistent.
- [ ] **G05** — As a project user, I want the correct GitHub repository icon and a new-tab link, so that I can reach the project reliably.
- [ ] **G08** — As a visitor, I want static route content, correct page metadata and a single hydrated interface, so that pages load and index correctly.
- [ ] **G09** — As a Safari web-app user, I want existing manifest, icons and standalone metadata preserved, so that the browser application continues to launch correctly.
- [ ] **D01** — As a frequent user, I want compact spacing and an immediately visible canvas, so that useful working content occupies the available screen.
- [ ] **D02** — As a canvas-tool user, I want narrow task controls beside the canvas and floating viewing controls, so that parameters remain close to the work.
- [ ] **D03** — As a tool user, I want borderless icon actions with visible hover, selection, disabled and keyboard-focus feedback, so that controls stay compact and understandable.
- [ ] **D04** — As a tool user, I want a blue primary, soft-blue secondary and distinct success, error, warning and information colors in both themes, so that hierarchy and feedback are clear.
