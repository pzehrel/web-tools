- [ ] **L10** — 作为设计者，我希望可开关优化，改变选项后自动重建，重建或关闭时使用原素材，以便预览始终表示有效的当前状态。
- [ ] **L11** — 作为设计者，我希望保留图集最大尺寸、间距和边缘扩展及其默认值和范围，以便打包控制完整。
- [ ] **L12** — 作为设计者，我希望保留旋转、保持动画位置的裁透明边与相同像素合并，以便继续使用既有优化选项。
- [ ] **L13** — 作为设计者，我希望可调整高级的二次幂、正方形图集和 alpha 阈值，以便设置详细图集约束。

- [ ] **L15** — 作为设计者，我希望对比前后字节、纹理数、像素与估算 RGBA 内存，标明增加，并查看占用率和去重统计，以便评估真实结果。
- [ ] **L16** — 作为设计者，我希望查看单张／多张图集，并独立适配、缩放／捏合、平移、显示倍率、边界和重置，以便不干扰主动画。
- [ ] **L17** — 作为设计者，我希望优化 ZIP 保留改写 data.json、编号图集 PNG 和必要的原始不可优化素材，以便导出项目仍可使用。

- [ ] **D09** — 作为 Lottie 用户，我希望使用图集优化、播放设置和项目记录标签，并常驻资源对比与导出，以便切换任务时保留结果上下文。
