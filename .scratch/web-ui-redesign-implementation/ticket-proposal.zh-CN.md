# 实施任务票拆分草案

Status: draft — awaiting breakdown approval
日期：2026-10-20
规范语言：英文

本草案将[已确认的规格](spec.zh-CN.md)拆成 12 张实施任务票，尚未发布可领取的正式任务，也不授权进入实施。[英文原文](ticket-proposal.md)具有相同范围和依赖。稳定的实现参考保留在[来源索引](sources.zh-CN.md)中。

## 每张任务票的共同规则

- 保留所分配需求 ID 的全部行为，包括规格中的默认值、边界、特殊情况和失败处理。这里的摘要不能替代详细契约。复用产品引擎和存储契约；原型覆盖不等于产品验收通过。
- 每张票完成并验证真实页面上的完整操作流程。迁移时，其范围之外的现有控件仍须可用。必要的组件提取包含在相应任务内并保持行为；不单设引擎重写或仅建设基础设施的阶段。
- 每条流程包含适用的亮暗主题、紧凑桌面布局、键盘与焦点行为、手机核心操作、空态／忙碌／错误反馈及相关模块测试。导出票检查解码后的产物或归档内容。记录票使用隔离测试数据、保留产品存储标识，验证刷新和旧记录。
- 遵循已评审的无边框图标按钮、语义颜色和浮动工作区。隐藏工具入口继续隐藏，直达路由保留。不增加数据位置宣传。
- 每张实施票执行要求的 lint、类型检查和构建。记录真实产品页面证据；无法执行的浏览器检查保持待验收，不能以源码检查替代。保留无关改动和原型参考。不包含提交、发版或部署。

## 建议任务票

### 01 — 首页、导航与正式主题

**依赖：** 无，可立即开始。

**交付：** 从已评审的紧凑首页进入任意公开工具，在页面左侧返回、切换工具、打开正确的 GitHub 链接，并在真实路由上保留跟随系统／浅色／深色偏好。

**主要需求：** G01–G05、G08–G09、D01–D04。05、07、09 也必须落实画布上的 D01–D02。

**验收重点：** 仅四个公开入口；保留重定向、隐藏直达路由和兜底；菜单与弹窗层级正确；主题按钮等大方形；正式蓝色主色及语义色不依赖开发开关；反馈和焦点清晰；水合后仅一份页面，元信息、manifest 与 Safari 行为正确。使正式设计规范与已确认决策一致。各工具工作区尚未迁移时，原功能仍可使用。

### 02 — URL 递归编辑与分享链接往返

**依赖：** 01 — 首页、导航与正式主题。

**交付：** 打开空白或分享 URL，查看并编辑所有嵌套层级，移动／新增／删除节点，复制原始或序列化内容，并在已确认布局中生成变量模板。

**主要需求：** U01–U10、U24–U25、D05–D06。

**验收重点：** 首行输入与居中二维码等高，下面依次为整行紧凑树和记录；03 迁移前保留二维码与记录控件。验证错误转义、重复／空值／标记参数、嵌套 hash 路由、基址后缀保留、行内提交／取消／焦点、所有插入与拖放目标及拒绝规则、删除确认、按深度编码的变量和复制。当前／旧文本／裸分享 hash 均可恢复，编辑防抖替换历史，清空移除分享 hash。示例通过明确操作加载。

### 03 — URL 二维码输入、直接下载与持久记录

**依赖：** 02 — URL 递归编辑与分享链接往返。

**交付：** 生成或识别二维码，查看放大后的树预览，直接下载对应图片，保存／更新／预览记录，并在刷新后恢复旧工作。

**主要需求：** U11–U23。

**验收重点：** 防抖、过期结果保护、选择／拖入／粘贴的输入保护和不同识别错误；页面下载纯二维码，弹窗下载二维码加参数，纯文本回退纯二维码，无下拉菜单。解码二维码，检查组合图尺寸／换行／省略及重试／忙碌行为。验证新保存与显式更新、命名／重命名、选择前预览、取消选择、复制、确认删除／清空及选择清理。保留 URL 原存储标识、旧数据转换和读取失败不阻塞操作。

### 04 — 帧素材导入、全宽序列与共同透明边裁剪

**依赖：** 01 — 首页、导航与正式主题。

**交付：** 导入图片、ZIP 或目录，在底部全宽序列中排序和勾选，裁剪共同透明边，并在清空或更换素材时保留序列规则。

**主要需求：** F01–F07、F19。建立 D07 的帧序列部分；05 补齐并验证进度条与序列的位置关系。

**验收重点：** 有效图片过滤、归档过滤、来源信息、新批次自然排序追加和显式全局排序；后续导入不改变已有手动顺序。验证前后拖排、全选／全不选／逐帧选择、稳定选择反馈且不跟随播放高亮、叠加裁剪预览、实时 alpha 边界、尺寸不同警告、取消／应用和结果像素。清空停止播放并重置依赖状态。现有播放／导出／记录操作仍可访问。

### 05 — 帧播放、独立进度与画布查看

**依赖：** 04 — 帧素材导入、全宽序列与共同透明边裁剪。

**交付：** 在默认可见的画布检查已选帧，通过序列上方的短进度条定位，设置时长／范围／方向／循环，并按预期恢复播放。

**主要需求：** F08–F14、D07–D08；落实 D01–D02。

**验收重点：** 窄左栏止于底部全宽序列上方，收起序列释放画布空间。定位暂停但不改变选择或导出／播放范围；继续播放遵守范围，有限循环结束后可正确重播。验证逐帧、缩略图定位、带输入保护的快捷键、FPS／时长／小数推算、包含端点的范围约束、正向／反向／往返、适配／平移／双指缩放／重置、仅影响查看的背景／边界和像素渲染。复用舞台测试并验证真实页面。

### 06 — 帧精灵图／代码导出与完整项目恢复

**依赖：** 05 — 帧播放、独立进度与画布查看。

**交付：** 将编辑后的序列输出为正确的精灵 PNG 与 CSS／Less／SCSS，并保存、刷新恢复完整项目。

**主要需求：** F15–F18、F20。04–05 同时验证各自操作反馈。

**验收重点：** 联动网格设置、实际输出预览／指标、来源最大单元尺寸和较小帧居中；检查导出像素。代码保留选择范围、时序、方向、循环、像素风格、变量和相对尺寸，具有复制反馈与仅代码全选。结合归档测试和真实页面验证素材字节／顺序／选择／裁剪阈值／播放／导出设置、命名／载入／删除、旧记录及空态／忙碌／失败恢复。

### 07 — Lottie 项目导入、播放与窄栏任务工作区

**依赖：** 01 — 首页、导航与正式主题。

**交付：** 导入支持的项目，用全部现有引擎／渲染器／适配方式检查动画，精确定位，并在已评审的窄左栏工作区查看消息。

**主要需求：** L01–L09、L19–L20、D10；落实 D01–D02。建立 D09 的任务标签布局，在 08 完成迁移前保留现有优化、资源对比、导出与记录入口。

**验收重点：** 单 ZIP 或完整目录且恰好一个有效 data.json；嵌套／相对／内嵌图片解析，缺失／不可读警告，不自动抓取远程图片。保留替换／示例／清空重置、两个库、canvas／SVG、meet／slice、小数进度、速度／方向／循环和主舞台手势。统一导入／元信息／视图控件，缩短播放条；素材消息位于左栏底部，警告／错误按规则展开且手机可达。验证换行、触摸和可滚动消息，不只验证成功导入。

### 08 — Lottie 图集优化、ZIP 验证与项目恢复

**依赖：** 07 — Lottie 项目导入、播放与窄栏任务工作区。

**交付：** 优化真实项目，检查独立浮动图集与资源前后对比，导出可用 ZIP，并恢复完整保存项目。

**主要需求：** L10–L18、D09。补齐 D10 的图集行为及相关 L19–L20 状态。

**验收重点：** 图集优化／播放／项目记录标签，对比与导出始终可达。保留所有打包选项／默认值／边界、重建开关和有效原素材回退、动态图排除、增量提示与详细指标。多图集独立查看、操作及重置。解压产物验证重写引用、图集 PNG、必要原素材／内嵌资源。验证具名完整持久项目与设置、旧记录兼容、载入／删除和异步失败恢复。复用素材、动态图检测、指标和记录归档测试；不要求新优化器或存储格式。

### 09 — 点九图切线、渲染与独立预览 HUD

**依赖：** 01 — 首页、导航与正式主题。

**交付：** 载入来源，用数值／指针／键盘调切线，查看实时边框渲染，移动／缩放浮动 HUD 且不误改输出尺寸。

**主要需求：** N01–N09、N11–N14、N18–N23、D11–D12；落实 D01–D02。10 验证 D11 中中心裁剪靠上的部分。

**验收重点：** 导入取消／类型／解码恢复，示例／默认值／清空正常路径，不交叉切线归一化及单独切线重置。保留绑定／解绑宽度、外扩、填充和双轴重复。验证八个内部逻辑尺寸手柄与八个 HUD 外部手柄、独立尺寸／位置、键盘步长、缩放换算、对边固定、视口边界和指针清理。来源／预览／HUD 重置独立，适配／手动接管和仅查看背景有效。中心裁剪保持靠上，迁移期间原输出／记录可用。

### 10 — 点九图自动分析、中心裁剪与像素导出

**依赖：** 09 — 点九图切线、渲染与独立预览 HUD。

**交付：** 自动分析切线，借助保留／删除区域细化常用中心裁剪，下载精确裁剪后的 PNG。

**主要需求：** N10、N15–N17；补齐 D11 的中心裁剪部分。

**验收重点：** 分析归一化切线／宽度／最小裁剪，提供忙碌／结果／错误且允许手动调整。保留双轴／X／Y、约束保留尺寸、最小操作、覆盖层解释和重复警告。解码 PNG 验证 1:1 四角／保留行列、尺寸与文件名；无有效裁剪时禁用，保留 CSS 切片数值，实时 border-image 预览仍以原图为来源。

### 11 — 点九图 CSS 复用与持久项目恢复

**依赖：** 09 — 点九图切线、渲染与独立预览 HUD。

**交付：** 复制准确的分项／简写 CSS，保存、恢复或删除完整点九图项目，包括较早的不完整记录。

**主要需求：** N24–N29。

**验收重点：** 紧凑四边值、图片路径提示、宽度／外扩／填充／重复轴、复制成功和仅代码全选。恢复来源字节与切线／渲染／裁剪／代码写法，完成归一化并显示记录名称／体积；空白时禁用保存。单条删除保留当前编辑器及其他记录。HUD／视图几何不存入记录或输出。10 不阻塞本票：现有裁剪参数与持久契约始终可用；12 验证最终界面的组合行为。

### 12 — 跨工具产品验收与原型隔离

**依赖：** 03 — URL 二维码输入、直接下载与持久记录；06 — 帧精灵图／代码导出与完整项目恢复；08 — Lottie 图集优化、ZIP 验证与项目恢复；10 — 点九图自动分析、中心裁剪与像素导出；11 — 点九图 CSS 复用与持久项目恢复。

**交付：** 从首页进入四个工具再返回的统一正式体验，保留已有工作，正式界面不依赖原型运行机制。

**主要需求：** G06–G07。集成验收覆盖全部 115 个需求 ID，复用任务级证据，不全量重复。

**验收重点：** 为每条需求补齐正式验收证据或明确阻塞的未解决结果。验证跨工具菜单／弹窗／HUD 层级，系统／浅／深主题，宽／紧凑桌面和约 390／320 像素手机核心操作、键盘输入保护及触摸。组合检查正式 SSG 水合／元信息、旧链接／记录和 Safari 资源。证明正式产品无 variant 切换器、原型数据库或开发专用色板依赖；保留设计参考与隐藏直达路由。集成后执行 lint／类型检查／构建。仍需真实产品浏览器证据；不包含部署。

## 依赖理由与覆盖

01 是唯一共同前置：在真实路由建立正式导航／主题契约。URL、帧动画、Lottie 和点九图随后可独立推进。各工具内部的后续流程依赖实际编辑／导入工作区。点九图裁剪与 CSS／记录在 09 后可独立推进。12 只列末端依赖；其前置任务通过依赖链自然纳入。

[机器可读草案](ticket-proposal.json)为 103 组现有功能和 12 项已评审 UI 决策各分配唯一主要负责票，并记录跨票检查。分配代表计划覆盖，不代表验收通过。不单设预重构票：引擎、归档和存储已经存在；提取适配层或组件可随首次跑通的流程完成。
