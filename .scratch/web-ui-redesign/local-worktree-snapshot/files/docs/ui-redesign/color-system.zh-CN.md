# 语义色彩评审

用户于 2026-10-19 要求主行动使用彩色，并明确主次层级及成功、失败、警告和提示色。本轮替代 F 原型的灰度覆盖，既有页面布局与操作保留。

| 角色 | 亮暗主题呈现                 | 当前用途                                                    |
| ---- | ---------------------------- | ----------------------------------------------------------- |
| 主色 | 蓝色实心填充，搭配对比前景色 | 主导出、二维码下载、激活的播放控件、焦点环和输入强调        |
| 次要 | 浅蓝填充，蓝色前景           | 次要操作、选中的任务标签与主题选项                          |
| 成功 | 绿色前景或浅绿填充           | 已确认的复制、点九图识别成功、帧动画裁剪完成                |
| 失败 | 红色前景与浅红填充           | 导入和裁剪失败；危险操作使用实心红色                        |
| 警告 | 琥珀色前景与浅琥珀填充       | Lottie 素材警告、帧尺寸不一致、无可裁剪内容、点九图平铺警告 |
| 提示 | 青蓝前景或浅色填充           | 无需裁剪的结果、等待处理与资源说明                          |

状态文字与既有图标继续伴随颜色显示。复制成功时短暂改变整个操作按钮的颜色，保证原本为实心主按钮时图标也可读。帧裁剪消息携带明确的类型化色调，界面不通过翻译文案字符串判断状态。

## 令牌与范围

全部色板数值集中在 [index.scss](../../apps/web/src/index.scss)。评审色板提供常规的 primary、secondary、foreground、background、input、border、ring 和 chart 令牌，以及 `success`、`warning`、`destructive`、`info` 的实色／前景／浅色背景／浅色背景前景四类令牌。组件通过语义工具类或变量引用。

[Vite](../../apps/web/vite.config.ts) 只为开发服务器启用 Sass 评审色板开关。挂载 F 原型时激活根节点的亮暗色板，让弹层与参数图片导出读取相同颜色。生产构建排除此评审色板，原有生产亮暗数值不变。共享令牌映射继续可用，不改变生产颜色。

本轮覆盖首页及共享原型样式，并为四个公开工具核对状态映射。隐藏工具继承共享样式，但其页面设计／评审仍暂缓。现有 `docs/DESIGN.md` 不在本轮改写为最终规范。

## 验证边界

源码色板通过亮暗主题共 52 组 sRGB 数值对比检查：核心文字组合的最低对比度为 5.45:1，输入令牌边界的最低对比度为 3.07:1。该检查针对实色令牌组合，不覆盖全部透明、禁用、图片或渐变状态。

Sass 检查确认开发时包含色板，生产时排除色板。仓库 lint、类型检查、生产构建和独立原型内存打包的结果记录在[验证记录](prototype-validation.json)。此前策略拒绝后，浏览器自动观察仍不可用；本轮不声称新增截图或亮暗主题实际验收。
