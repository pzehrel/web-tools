## Scope exclusions

- Existing promotional copy about local processing, data location or not uploading is content, not a protected capability. The user's instruction to remove that emphasis remains effective.
- The frontend currently chooses IndexedDB even if a server URL is configured. An HTTP store, account UI or cloud synchronization is not an implemented frontend feature to preserve in this audit; server work is outside this redesign.
- Pixel-perfect old layout, color, card styling and exact label wording are not fixed. Input/output semantics, capabilities, state transitions, accessibility of operations and compatibility remain the functional baseline.
