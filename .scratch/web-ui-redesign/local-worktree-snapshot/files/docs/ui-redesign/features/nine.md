No browser interactions or runtime tests were performed for this inventory. “Covered” means the corresponding behavior is wired in the F source, not that it has passed runtime acceptance. “Partial” means only part of the existing contract is wired; “missing” means F has no corresponding interaction. All existing capabilities below must survive the UI redesign unless the user explicitly approves a functional change. F is a visual and interaction proposal, not the feature specification.

The product already has a resizable preview. Making that preview a floating panel is a new F layout proposal; it is not an existing product layout. Source audits must distinguish the existing resize capability from its proposed placement.

## Scope corrections and existing limitations

- Current callable output is **CSS only**, in longhand or shorthand. `NinePatchRecordMeta.codeFormat` allows `scss | less | css`, but `makeRecordMeta` writes `css`, `buildCode` only generates CSS, and there is no format selector. The SEO description still mentions SCSS/Less; it is not proof of shipped generators. No Tailwind generator was found. These are documentation/schema inconsistencies, not F regressions or existing functions to invent.
- The existing live preview renders the original source with `border-image`; center cropping previews deletion geometry on the source and exports a compact PNG. There is no claim that the live preview already swaps in a generated cropped bitmap.
- Records do not currently save preview dimensions, stage zoom/pan, boundary/background preferences or automatic-detection feedback. Do not describe restoration of these as existing behavior.
- The shared store exposes loading state, but the nine-patch page does not render loading/error feedback for record operations. Missing record/decode data returns silently in `loadRecord`; record deletion has no confirmation. Preserve actual usable states; improvements may be proposed separately, without presenting them as existing features.
- F's collapsible floating parameter panel, floating preview placement, preview width slider/reset and guide visibility switch are design additions. They do not compensate for missing crop, analysis, width, repeat or persistence workflows.
