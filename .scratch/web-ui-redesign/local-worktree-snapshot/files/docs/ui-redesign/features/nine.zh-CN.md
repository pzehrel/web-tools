本清单于 2026-10-18 核查当前工作区源码，没有为本次清单操作浏览器或进行运行时测试。“已覆盖”表示 F 源码已接通对应行为，不表示已经通过运行验收；“部分覆盖”表示仅接通现有行为契约的一部分；“未覆盖”表示 F 没有对应交互。除非用户明确同意功能变更，后续 UI 重设计必须保留以下全部现有能力。F 是视觉和交互提案，不是功能规格。

## 范围纠正与现有限制

- 当前可调用输出**只有 CSS**，支持分开写和简写。`NinePatchRecordMeta.codeFormat` 允许 `scss | less | css`，但 `makeRecordMeta` 写入 `css`，`buildCode` 只生成 CSS，也没有格式选择器。SEO 描述仍提到 SCSS／Less，不能证明已交付生成器。没有发现 Tailwind 生成器。这些属于文案／结构不一致，不是 F 的回归，也不是需要编造的现有功能。
- 当前实时预览使用原始源图的 `border-image`；中心裁剪在源图上预览删除几何并导出紧凑 PNG。这里没有声称实时预览已经换用生成后的裁剪位图。
- 当前记录不保存预览尺寸、舞台缩放／平移、边界／背景偏好或自动识别反馈。不能把这些状态的恢复描述为现有能力。
- 公共存储提供 loading 状态，但点九图页没有渲染记录操作的加载／错误反馈。`loadRecord` 遇到缺失记录／解码数据会静默返回，删除记录没有确认。应保留实际可用状态；改进可以另提，不能描述成现有功能。
- F 的可折叠浮动参数面板、浮动预览位置、预览宽度滑块／重置与辅助线可见开关是设计新增项，不能抵消裁剪、分析、宽度、重复或持久化流程缺失。
