## 边界与验证

新设计没有独立的“解析结果”板块，可编辑树是主要结构化视图。移除新增的原型摘要区，不授权删除解析、变量、二维码互转或记录能力。

此前原型浏览器检查覆盖了嵌套编辑、插入／焦点、拖入嵌套、变量复制、内存记录操作、二维码详情、两种下载、图片识别及手机树编辑。这不能证明持久记录、旧数据迁移或 hash 兼容，因为 F 未实现这些部分。源码一致也不代表本轮重新实测了所有解析边界或所有浏览器。
