## Question

在真实、当前可访问的同类工具网站中，哪些首页入口、工具切换、编辑工作区、参数和输出组织方式，适合本项目的四个公开工具与既定任务？

阅读第一方页面，结合实际界面截图区分可观察事实与设计推断，记录具体来源、可以借鉴和不适合照搬的部分。不要只收集营销首页或泛化风格形容词，也不把外部产品的功能加入本项目。

继续遵循桌面优先、手机核心可用、语义颜色令牌、首页直达工具和页头工具切换的既定边界。候选界面不宣传数据所在地或隐私处理机制。结论作为下一轮视觉原型的输入，不替用户选定视觉方向。

## Answer

参考研究已完成，具体证据集中在[同类工具网站 UI 参考研究](../research/comparable-tool-sites.md)。结论是按任务组合 iLoveIMG 的入口及状态、IT Tools 的文本输入结果、SVGOMG／Squoosh 的画布与邻近操作，制作一套有来源的候选验证；不把任何参考站当作用户已经喜欢的风格。
