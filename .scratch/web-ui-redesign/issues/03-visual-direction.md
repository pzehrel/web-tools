## Question

在同样的真实内容、核心任务和功能约束下，哪一种视觉方向最适合这套工具？

采用[确定重设计服务的核心任务与设备边界](01-target-workflows.md)选定的共同任务，按 prototype 技能提供数种有明显差异的候选，以首页和代表工具页为共同样本，让用户比较排版、密度、层级、颜色、形状与亮暗主题。候选不能只换配色，也不能凭空增加产品能力。

通过用户对具体原型的反馈选择方向，并记录接受和拒绝的理由。若用户明确指定参考，先检验是否仍需多个方向，再调整本票问题；不能自行把现有规范当作答案。

原型链接作为附件记录在本票；原型只回答设计问题，不表示已获准直接替换全站产品实现。
