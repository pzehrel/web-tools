## Question

全站哪些组件和交互应遵循同一套规则，哪些必须允许工具按任务定制？

依据[用可比较的原型选择全站视觉方向](03-visual-direction.md)和[用代表工具验证工作台布局与主要操作链路](04-workbench-interaction.md)的结论，确定标题、导航、按钮层级、字段、分段选择、帮助、反馈、弹层、舞台操作与主题的共同约定，明确焦点、键盘、触屏和可读性要求。

输出能被实现者直接采用的规则边界，并指出旧规范应保留或替换的部分。各工具尚不清晰的状态细节另立后续票，不在本票中用假设填满。
